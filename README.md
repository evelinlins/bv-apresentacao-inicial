# 🏛️ BRÍVEN Society 

> *Onde a inteligência financeira encontra a precisão do marketing.*

Portal web e hub integrado estruturado sob a identidade visual **Dark Elegance**, unindo a consultoria de marketing estratégico e posicionamento de marca ao ecossistema de tecnologia financeira e inteligência de dados (**ExtratoTurbo**).

-

# Identidade Visual & Conceito
* **Paleta de Cores:** Roxo Escuro Berinjela (`#1a0b2e`), Verde Escuro Esmeralda (`#0b3c2d`), Dourado Suave (`#d4af37`) e Creme Off-White (`#f4f0ea`).
* **Tipografia Editorial:** Estética sóbria, limpa e profissional baseada em Montserrat e refinamentos visuais personalizados.
* **Fonética da Marca:** *Bríven* (enfatizado no acento agudo).

-

# O Projeto Inicial: ExtratoTurbo
O **ExtratoTurbo** é a ferramenta central e inicial de inteligência financeira do ecossistema. Desenvolvida para eliminar planilhas manuais, a plataforma processa extratos bancários brutos (`.xls` ou `.ofx`) de múltiplos bancos e entrega:
* **Normalização e Unificação:** Consolidação automática de dados financeiros.
* **Categorização por Inteligência Artificial:** Reconhecimento preciso de gastos e tagueamento inteligente.
* **Geração de Insights & Relatórios:** 6 gráficos interativos, relatórios analíticos detalhados e diagnósticos preditivos sobre hábitos de consumo e vilões do orçamento.

-

# Stack Tecnológica
Projeto 100% estático, leve e de alta performance, pronto para deploy contínuo:
* **HTML5 Semantic**
* **CSS3** (Custom Properties / Variáveis, Flexbox e CSS Grid)
* **JavaScript Vanilla** (Interatividade e manipulação de DOM)
* **Web Storage API (`localStorage`)** para persistência de dados local no navegador do usuário
* **Chart.js** (Biblioteca de visualização de dados interativos)
* **Git, GitHub & GitHub Pages** (Versionamento e Hospedagem)
